# Workflow

## Step 1

The Gmail Trigger continuously monitors the configured Gmail inbox.

---

## Step 2

Whenever a new email containing Python code is received, the code is extracted.

---

## Step 3

The workflow branches into two parallel AI pipelines.

### Branch A

Generate a beginner-friendly summary.

### Branch B

Generate commented Python code.

---

## Step 4

Merge the outputs.

---

## Step 5

Aggregate the generated responses.

---

## Step 6

Convert the merged response into an HTML email.

---

## Step 7

Automatically send the generated documentation back to the user using Gmail.
